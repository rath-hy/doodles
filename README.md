# doodles

An experiment about whether perspiration begets inspiration. 

Every day I will set aside 30 minutes to follow my curiosity wherever it leads, and keep whatever comes out.

Nothing here needs to be finished, useful, or good.

## Layout

One folder per project, prefixed with the date it started:

```
2026-10-29-some-idea/
2026-11-02-another-thing/
```

The date prefix makes the folder list double as a log of the habit.

Each project can have a short README with what sparked it and where it ended up.
